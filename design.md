# SubReel — Mobile Interface Design

## Product Direction

SubReel aik Flutter/Dart caption generator hai jo creators ko device se video import karne, captions generate karne, unhein style karne, aur captioned MP4 ya subtitle file export karne deta hai. MVP Android-first hoga. App ka Cloudflare Worker endpoint build mein fixed hoga aur provider key app ya user ko kabhi nahi dikhayi jayegi.

## Mobile Layout Principles

Har screen 9:16 portrait use case aur aik haath se use karne ko madde-nazar rakh kar banegi. Safe areas, minimum 44dp tap targets, aur bottom actions ko thumb reach ke qareeb rakha jayega. Editor mein video preview landscape media ko fit karega, lekin screen portrait hi rahegi.

## Screen List

| Screen | Primary content | Main actions |
| --- | --- | --- |
| Projects | Saved projects ka grid ya empty state | Project kholna, project menu, naya project banana |
| New Project sheet | Video import chooser aur disabled future link option | Device se video select aur import confirm karna |
| Transcribing | Progress indicator aur current pipeline step | Cancel karna ya failed chunk retry karna |
| Editor — Preview | Video player, caption overlay, template chips aur export CTA | Playback, template apply, customize panel kholna |
| Editor — Transcript | Editable caption blocks aur timeline controls | Word correct, segment merge/split, undo/redo |
| Customize sheet | Font, color, position aur animation controls | Caption style change aur preview update |
| Export | Output format, resolution aur render progress | MP4 ya subtitle file export, save/share |
| Profile | App preferences aur privacy information | Preferences dekhna aur back navigation |

## Key User Flows

Projects screen par plus button dabane se New Project sheet khulegi. User MP4 ya MOV choose karega; import ke baad secure app service captions create karegi aur user Editor mein jayega. User API key enter nahi karega. Editor mein user template select karke caption styling adjust karega, transcript ko edit karega, aur Export screen se captioned MP4 ya SRT, VTT, ASS file save/share karega. Har edit local project storage mein auto-save hogi. Existing project card ko long-press karne se destructive confirmation bottom sheet khulegi.

## Visual System

Design reference ki floating navigation, bara confident heading aur negative space se mutasir hai, magar app ki apni interface identity rakhega. User ki black-and-white requirement ko follow karte hue MVP mein koi coral ya rangin accent nahi hoga.

| Element | Color / specification |
| --- | --- |
| Canvas | `#090909` near-black AMOLED background |
| Surface | `#181818` with `#2B2B2B` one-pixel border |
| Elevated panel | `#202020` with restrained shadow and subtle transparency |
| Primary text | `#FFFFFF` |
| Secondary text | `#A1A1A1` |
| Disabled text | `#5E5E5E` |
| Active control | White fill with black icon/text |
| Primary action | White pill/squircle with black label |
| Destructive state | `#FF6B6B`, only where warning clarity is necessary |
| Heading | Manrope Light/Regular with restrained size and letter spacing |
| Interface text | Manrope Medium/Regular |

Home heading exactly `Projects` hoga; product name home chrome mein nahi hoga. Header ke right side par simple outlined profile icon hoga. Floating dark navigation capsule, active white circular home chip, aur separate white squircle plus button lower edge par honge. Project cards 20dp radius, dark surface, 16:9 ya 9:16 thumbnail aur clear text hierarchy rakhenge. Long press par black destructive confirmation sheet hogi jismein `Delete project?`, project name, secondary `Cancel` aur outlined destructive `Delete` action hoga. New Project sheet ki poori copy English mein hogi, jismein short trust text hoga: `Captions are generated by SubReel. No API key needed.`

## MVP Boundaries

MVP device video import, hardcoded secure Worker access, transcript editing, eight local style presets, local project persistence, aur export-ready rendering architecture cover karega. YouTube import, translation, cloud sync aur paid credit logic intentionally Phase 2 mein rahenge. Provider key source code, Flutter storage, aur release APK mein kabhi nahi hogi.

## Timeline Editor Update

Editor ab stacked cards ki jagah vertical timeline workspace hoga. Top bar mein back, help aur Export action honge. Upar actual video preview, neeche scrub/play transport aur simple thumbnail-style timeline rahegi. Active playhead transcript segment ke saath move karega.

| Tool | Primary action | Bottom-sheet contents |
| --- | --- | --- |
| Templates | Caption style preset select karna | Horizontal live style previews aur apply action |
| Effects | Caption animation/effect choose karna | None, Pop, Fade, Karaoke aur Bounce options |
| Subtitles | Generated captions manage karna | Show/hide, transcript list, caption position aur text controls |
| Video | Video-level controls | Mute, trim placeholder, fit mode aur replace-video action |
| B-roll | Future video overlays entry point | Informative empty state; no false B-roll processing claim |

Tool rail bottom safe area ke upar rahegi aur har item 44dp se bara tap target rakhega. Sheet half-height, dark surface aur clear drag handle ke saath khulegi. Black-and-white language maintain rahegi; selected state white fill aur black icon/text se show hogi. Accent color sirf selected animated caption color controls mein optional rahega.
